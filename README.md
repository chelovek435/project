# Интерактивная карта достопримечательностей

Курсовой проект по модулю PyQt (Яндекс Лицей).

## Описание
Приложение для просмотра и управления базой данных городов и достопримечательностей. 
Реализован интерактивный интерфейс с картой мира, масштабированием, слоями и галереей фотографий.

## Ключевые возможности
* **Интерактивная карта:** плавное перетаскивание (зажатой ЛКМ) и масштабирование (колесиком мыши) с мгновенными подсказками при наведении на маркеры.
* **Динамический масштаб:** автоматический расчёт километров и метров на экране с отображением шкалы в реальном времени.
* **Карточки объектов и умные клики:** 
  * При клике на **город** открывается окно с его координатами и кликабельным списком достопримечательностей для быстрого перехода к ним.
  * Если несколько **достопримечательностей** находятся слишком близко друг к другу, появляется контекстное меню для выбора нужной.
* **Взаимодействие с таблицами:** двойной клик по строке перемещает карту к объекту, а выбранную достопримечательность подсвечивает зелёным маркером (сброс выделения — по клавише `Esc`).
* **Галерея изображений:** просмотр фотографий достопримечательности с переключением стрелками или клавишами `Q`/`E` (`Й`/`У`). При добавлении новых фото файлы автоматически копируются в папку проекта.
* **Управление слоями и данными:** панель для скрытия/показа городов и достопримечательностей, валидация координат при вводе и каскадное удаление записей в БД.
* **Гибкий экспорт/импорт:** сохранение базы в Excel (`.xlsx`), CSV (`.csv`) или копию базы (`.db`). Импорт таблиц поддерживает два режима: дополнение/обновление текущей базы или её полную замену.

## Технологии
* Python 3.11
* PyQt6 (графический интерфейс, `QGraphicsView` для карты)
* SQLite3 (реляционная база данных)
* openpyxl, csv (импорт/экспорт)

## Как запустить
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите программу:
   ```bash
   python main.py
   ```
3. Для запуска готовой сборки откройте `InteractiveMap.exe` (папка `data` должна лежать рядом с exe-файлом).

## Структура проекта
* `main.py` — основной файл, точка входа.
* `Map` (класс) — отвечает за отрисовку карты, маркеров, зум и масштаб.
* `Project` (класс) — главное окно, связывает интерфейс с базой данных.
* `InfoDialog`, `CityDialog`, `AtrDialog` — кастомные диалоговые окна для просмотра и редактирования.
* `UI/` — скомпилированные интерфейсы из Qt Designer.
* `data/` — база данных `data.db`, карта и папка `photos` с картинками.
* `demo/` — тестовые файлы для проверки функции импорта.
