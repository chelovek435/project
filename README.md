## Технологии
* Python 3.11
* PyQt6 (графический интерфейс, `QGraphicsView` для карты)
* SQLite3 (реляционная база данных)
* openpyxl, csv (импорт/экспорт)

## Как запустить
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите программу:
   ```bash
   python main.py
   ```
3. Для запуска готовой сборки откройте `InteractiveMap.exe` (папка `data` должна лежать рядом с exe-файлом).

## Структура проекта
* `main.py` — основной файл, точка входа.
* `Map` (класс) — отвечает за отрисовку карты, маркеров, зум и масштаб.
* `Project` (класс) — главное окно, связывает интерфейс с базой данных.
* `InfoDialog`, `CityDialog`, `AtrDialog` — кастомные диалоговые окна для просмотра и редактирования.
* `UI/` — скомпилированные интерфейсы из Qt Designer.
* `data/` — база данных `data.db`, карта и папка `photos` с картинками.
